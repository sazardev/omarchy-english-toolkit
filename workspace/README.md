# English workspace

Everything you produce while learning English. One folder per phase.

```
English/
  WORKFLOW.md      <- read this first. The method, not the tools.
  journal/         daily log, one file per day
  writing/         your writing, one file per day, auto-created
  readings/        EPUB and PDF files for Lute
  listening/       subtitles, auto-created by enlisten
  transcripts/     shadowing material
  vocabulary/      words worth keeping
  errors/          your recurring mistakes, ranked by english-daily errors
  templates/
  .state/          progress log, do not edit
```

Start every day with:

```bash
english-daily
```
